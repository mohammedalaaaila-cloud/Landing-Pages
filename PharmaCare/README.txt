Project Description

This project is a front-end only web prototype designed for a local pharmacy called PharmaCare.
The website provides a clear and visual dashboard that helps pharmacy staff quickly identify medicine availability and expired items, while also serving as a simple marketing interface for customers.

The project is fully static and built using only HTML5 and CSS3, without any backend or JavaScript functionality.

Website Pages

The website consists of three main pages:

Home (index.html)
A marketing and overview page that introduces the pharmacy, displays services, and shows a dashboard summary with static statistics.

Medicine Inventory (inventory.html)
Displays a complete list of medicines with their category, stock status, and expiry date.
Stock status is visually represented using colors (green for in stock, red for out of stock).

Expiry Tracker (expiry.html)
Shows only expired medicines with clear warning styling to alert staff for immediate action.

Technologies Used

HTML5

CSS3

CSS Grid for layout

Responsive design (mobile, tablet, desktop)

How to Run the Project

Download and extract the project folder.

Open the file index.html in any modern web browser.

Use the navigation menu to move between pages.

Design Notes

A medical-themed color scheme (blue, green, red for alerts) was used.

All data is hard-coded directly in the HTML files.

Expired medicines are highlighted using distinct styling.

The design is fully responsive without using JavaScript.
