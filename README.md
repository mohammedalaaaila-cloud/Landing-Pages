* # The Second One – PharmaCare Web Prototype

## Description

A front-end only web prototype designed for a local pharmacy called PharmaCare. The website provides a clear and visual dashboard to help pharmacy staff track medicine availability and expired items, while also serving as a simple marketing interface for customers.

## Overview

This project is a fully static website built using only HTML5 and CSS3, without any backend or JavaScript functionality.

It combines both marketing and internal dashboard features in a clean and responsive design.

## Website Pages

### Home (index.html)

A marketing and overview page that introduces the pharmacy, displays services, and includes a dashboard summary with static statistics.

### Medicine Inventory (inventory.html)

Displays a complete list of medicines including:

* Category
* Stock status
* Expiry date

Stock status is visually represented using colors:

* Green for in stock
* Red for out of stock

### Expiry Tracker (expiry.html)

Shows only expired medicines with clear warning styling to alert staff for immediate action.

## Technologies Used

* HTML5
* CSS3
* CSS Grid
* Responsive Design (mobile, tablet, desktop)

## How to Run the Project

1. Download and extract the project folder
2. Open `index.html` in any modern web browser
3. Use the navigation menu to move between pages

## Design Notes

* Medical-themed color scheme (blue, green, red for alerts)
* All data is hard-coded in HTML files
* Expired medicines are highlighted with distinct styling
* Fully responsive design without JavaScript
